# Dataset Information

## Malaria Cell Images Dataset

The dataset contains blood cell images classified into two categories:

- **Parasitized:** Cells containing malaria parasites.
- **Uninfected:** Cells without malaria parasites.

## Download Dataset

[Download the Malaria Cell Images Dataset](https://drive.google.com/file/d/1GskERNoEPTDsfGqnOaYf12HhJpVU6AMh/view?usp=sharing)

## Instructions

1. Download the ZIP file.
2. Extract `cell_images.zip`.
3. Ensure the `Parasitized` and `Uninfected` folders are available in the dataset location expected by the notebook.

The dataset is hosted externally because the complete image collection is too large for a standard GitHub repository.
