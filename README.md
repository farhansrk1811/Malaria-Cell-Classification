# Malaria Cell Classification

## Project Overview
This project focuses on classifying malaria-infected and uninfected blood cell images using Python, image processing, and deep learning techniques.

The classification task includes two categories:
- **Parasitized:** Blood cell images containing malaria parasites.
- **Uninfected:** Blood cell images without malaria parasites.

## Project Objectives
- Locate and verify the malaria cell image dataset.
- Explore and visualize sample blood cell images.
- Examine image dimensions and dataset structure.
- Prepare image data for classification.
- Develop and evaluate a model for malaria cell classification.

## Technologies Used
- Python
- Jupyter Notebook
- Image processing and visualization libraries
- Machine learning and deep learning libraries used in the notebook

## Dataset
The dataset contains 27,560 blood cell images across two classes.

**Download the dataset:** [Malaria Cell Images Dataset (Google Drive)](https://drive.google.com/file/d/1GskERNoEPTDsfGqnOaYf12HhJpVU6AMh/view?usp=sharing)

After downloading `cell_images.zip`, extract it so the notebook can access the following folder structure:

```text
dataset/
└── cell_images/
    ├── Parasitized/
    └── Uninfected/
```

Place the dataset folder relative to the notebook as expected by the code.

## Project Files
- `Malaria_Cell_Classification.ipynb`: Jupyter Notebook containing the project workflow, code, analysis, and outputs.

## How to Run
1. Clone or download this repository.
2. Install the Python libraries required by the notebook.
3. Download the dataset using the Google Drive link above.
4. Extract the images into the expected folder structure.
5. Open `Malaria_Cell_Classification.ipynb` in VS Code or Jupyter Notebook.
6. Select a compatible Python kernel and run the notebook cells in order.
